This is an example post. To remove it, delete this file, its link in the blog index, and its entry in docs/terminal.js.

Posts are hand-written HTML files, so adding one takes four steps.

  1. Copy docs/blog/example-post.html to docs/blog/my-post.html.
  2. In the copy, update the title, description, breadcrumb, heading and date. Then replace this text with your own.
  3. Add the post to the file list in docs/terminal.js.
  4. Add a link to the top of the list in docs/blog/index.html:
<li>
  <time datetime="2026-11-02">2026-11-02</time>
  <a href="my-post.html">My post</a>
</li>

Keep links and asset paths relative, as in this file, so the site works under any base path.
